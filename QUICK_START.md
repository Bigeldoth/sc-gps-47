## TL;DR

```powershell
# Prerequisites: Python 3.10+ and Tesseract OCR (https://github.com/UB-Mannheim/tesseract/wiki)

git clone https://github.com/Bigeldoth/sc-gps-47.git
cd sc-gps-47
python -m pip install -r requirements.txt
python src/main.py
```

In-game, open the console (`` ` ``) and type `r_DisplayInfo 3` to display the debug HUD that SpaceDrive will read.

Shortcuts: `Shift+F1` toggle overlay · `Shift+F3` snapshot POI · `Shift+F4` POI manager.
