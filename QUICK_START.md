## TL;DR

```powershell
# Prérequis : Python 3.10+ et Tesseract OCR (https://github.com/UB-Mannheim/tesseract/wiki)

git clone https://github.com/Bigeldoth/sc-gps-47.git
cd sc-gps-47
python -m pip install -r requirements.txt
python src/main.py
```

En jeu, ouvrir la console (`` ` ``) et taper `r_DisplayInfo 3` pour afficher le HUD debug que SpaceDrive va lire.

Raccourcis : `Shift+F1` toggle overlay · `Shift+F3` snapshot POI · `Shift+F4` gestionnaire POI.
