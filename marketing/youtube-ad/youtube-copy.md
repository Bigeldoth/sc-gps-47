### Description

```
Star Citizen marks the stations. It does not mark the cave you found, the wreck you
looted or the landing pad nobody else knows about. SpaceDrive GPS does.

It is a free, open-source overlay that reads the coordinates from the game's own debug
HUD and turns them into real navigation: distance to your target, heading, and a live
freshness indicator, on top of the game.

Download & community POIs → https://spacedrive.padek-interactive.tech

── WHAT IT DOES ──────────────────────────────────

• Save any position with one hotkey (Shift+F3). The coordinates are frozen at the exact
  moment you press it, so the value cannot drift while you name the spot.
• Pick a saved spot as your target and fly: the overlay shows the distance counting down
  and the turn you need to make, car-GPS style.
• Coordinate colours track data freshness — green when the read is live, amber as it ages,
  red when it is lost. Lose the read for a second and it coasts on your last velocity
  instead of dropping the arrow.
• Eight POI categories (hidden, cave, circuit, tactical, industry, logistics, loot,
  racing), shared with the SpaceDrive Community Hub.
• Import and export your POIs by clipboard or JSON file — share a spot with your org,
  publish it on the Hub, or keep it to yourself.

── HOW IT WORKS ──────────────────────────────────

SpaceDrive is 100% external. It takes screenshots of the debug HUD and reads them with
OCR — no memory reading, no DLL injection, no game file modification. The overlay is a
normal always-on-top window that ignores your mouse, so it never steals a click from
the ship.

To use it, enable the debug HUD in game: open the console (` key) and type
r_DisplayInfo 2. That is the whole setup.

── GET IT ────────────────────────────────────────

Website & community POIs: https://spacedrive.padek-interactive.tech
Source code (GPLv3): https://github.com/Bigeldoth/sc-gps-47

Windows 10 / 11. Free and open source. The installer pulls in the OCR engine on its own;
an optional GPU engine can be added later from the options.

SpaceDrive GPS is an unofficial tool. It is not affiliated with, endorsed by, or
sponsored by Cloud Imperium Games. Star Citizen is a trademark of Cloud Imperium Rights LLC.
```
